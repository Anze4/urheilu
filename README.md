Urheilutulossovellus

Kuvaus
Tämä on React Native mobiilisovellus, jonka avulla käyttäjä voi hakea urheilujoukkueita ja tarkastella niiden ottelutuloksia, tulevia otteluita sekä sarjataulukkoa. Sovellus näyttää myös joukkueen kokoonpanon ja yksittäisen pelaajan tiedot.

Käytetyt teknologiat

React Native 
Expo = sovelluksen kehitys ja ajaminen
JavaScript 
REST API (TheSportsDB) = urheiludatan hakeminen
 Fetch API = datan hakeminen internetistä
 react-native-safe-area-context = turvallinen näkymä mobiililaitteille

 Ominaisuudet

 Joukkueen haku
 Viimeisimmät ja tulevat ottelut
Sarjataulukko
 Joukkueen kokoonpano
 Pelaajan profiilinäkymä
 Mahdollisuus avata joukkue sarjataulukosta
